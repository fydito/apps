PDF Tools

Apps de Fydito · Tus archivos, a tu manera

📄 Herramientas PDF

Uní, separá o creá PDFs directamente en tu navegador. Los archivos se procesan localmente.

🔗 Unir varios PDFs

Agregá PDFs desde una o varias carpetas. Podés cambiar el orden antes de unirlos.

✂️ Separar / extraer páginas

Ejemplo: 1-3, 5, 8-10.

🔃 Reordenar páginas

Elegí un PDF y arrastrá las páginas para cambiar su orden. También podés usar las flechas.

🖼️ Imágenes → PDF

Seleccioná una o varias imágenes. Cada una ocupará una página.

📝 Texto → PDF

📄 Convertir PDF a Word

Seleccioná un PDF para convertirlo a un documento Word editable (.docx) mediante Adobe PDF Services.

La conversión se abre en otra pestaña y puede demorar. El archivo se envía a SIGRI y a Adobe para procesarlo; las demás herramientas PDF siguen funcionando localmente.

Las herramientas habituales procesan archivos localmente · PDF → Word utiliza Adobe a través de SIGRI
